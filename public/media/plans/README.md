# Site layout PDFs

Drop plan PDFs here. The Site Preparation → **Site layout plans** viewer loads them.

## Expected filenames

| File | Used for |
|------|----------|
| `greenfield-master-layout.pdf` | Greenfield master layout |
| `greenfield-infra-layout.pdf` | Greenfield infrastructure layout |
| `demo-site-layout.pdf` | Riverside / Lakeview demo |

After adding a file, refresh the app. If the browser can’t embed the PDF, use **Open** / **Download** from the viewer toolbar.
